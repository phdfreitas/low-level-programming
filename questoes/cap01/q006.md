# Questão 6

## Arquitetura de von Neumann

> Quais são os principais problemas que as extensões modernas do modelo de von Neumann tentam resolver?

Os problemas que os modelos modernos tentam solucionar são principalmente:
1. Nada é possível sem consultar a memória lenta **[registradores e cache]**
2. A falta de interatividade da arquitetura **[falta de interatividade]**
3. Qualquer programa pode executar qualquer instrução **[anéis de proteção]**

- A arquitetura de von Neumann não é apropriada para multitarefa
4. Sem suporte para isolamento de código em procedimentos ou para salvar contexto **[pilha de hardware]**
5. Os programas não estão isolados uns dos outros **[memória virtual]**
